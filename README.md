
# AURIX – Gold Price Trend Snapshot & Savings Insight

AURIX is a Python-based gold price analytics application developed to explore recent gold price movements, identify trends and present data-driven insights through an interactive dashboard.

## Live Application

[Launch AURIX – Gold Analytics](https://aurix-gold-analytics.streamlit.app/)

## Project Overview

AURIX demonstrates the practical application of Python and data analytics to financial market data. The application analyses recent gold price movements and uses moving-average calculations to generate a trend-based analytical signal.

The project was developed as a hands-on learning initiative combining programming, data analysis, AI-assisted development and interactive visualisation.

## Key Features

- Gold price trend analysis using recent historical data.
- Moving-average calculations.
- Trend-based analytical signal.
- Interactive data visualisation.
- Browser-accessible dashboard.
- Python-based analytical logic.
